# نگهبان — اپلیکیشن کنترل والدین

اپلیکیشن اندرویدی کنترل والدین با رابط کاربری فارسی و راست‌چین، تم دارک نئون، همراه با پنل مدیریت تحت وب.

## امکانات

- **قفل برنامه‌ها**: انتخاب برنامه‌های حواس‌پرت‌کن (اینستاگرام، یوتیوب، تلگرام و...) برای کنترل
- **زمان‌بندی هوشمند**: قفل خودکار برنامه‌ها در بازه‌های مشخص (مثلاً هر شب ۲۲:۰۰ تا ۰۶:۰۰)
- **حالت تمرکز**: قفل موقت همه برنامه‌های کنترل‌شده برای ۱۵ تا ۹۰ دقیقه
- **آمار مصرف**: نمودار ۷ روز اخیر + پرمصرف‌ترین برنامه‌ها
- **رمز والد**: دسترسی والد با رمز ۴ رقمی برای تغییر تنظیمات، استراحت موقت و لغو قفل
- **گزارش در پنل وب** (هر ۱۵ دقیقه):
  - لیست برنامه‌های نصب‌شده + وضعیت کنترل
  - مصرف روزانه هر برنامه (۷ روز اخیر) و درصد باتری
  - **لیست پیامک‌ها** (دریافتی/ارسالی، با جستجو و **خروجی CSV**)
  - **لیست مخاطبین** (با جستجو و **خروجی CSV**)
  - **اعلان‌های گوشی** (عنوان و متن اعلان هر برنامه)
  - **گالری عکس‌ها** (ایندکس + پیش‌نمایش با قابلیت **دانلود تک‌تک عکس‌ها**)
- **موقعیت روی نقشه**: در هر همگام‌سازی، آخرین موقعیت برای پنل فرستاده می‌شود و در پنل روی نقشه‌ی جهان با نقطه‌ی دقیق + زوم نمایش داده می‌شود
- **عکس‌برداری از کاربر گوشی**: به فرمان والد از پنل، دوربین جلو بی‌صدا عکس می‌گیرد و در پنل ظاهر می‌شود
- **قفل فوری**: قفل کردن همه برنامه‌های کنترل‌شده با یک کلیک
- **مخفی‌سازی از منو**: حذف آیکون برنامه از منوی گوشی با یک دکمه — سرویس‌ها روشن می‌مانند
- **اجرای همیشگی**: پایش با WakeLock حتی وقتی صفحه خاموش است + بازگشت خودکار بعد از ری‌استارت گوشی
- **بدون اعلان**: سرویس هیچ نوتیفیکیشن و صدایی ندارد (در اندروید ۱۳+ کاملاً مخفی)
- **نام نمایشی «روبیکا»**: برنامه روی منو و تنظیمات گوشی با نام «روبیکا» دیده می‌شود

## معماری

| فناوری | کاربرد |
|--------|---------|
| Kotlin + Jetpack Compose | رابط کاربری مدرن و declarative |
| Material 3 | کامپوننت‌های Material |
| Room | ذخیره‌سازی برنامه‌های کنترل‌شده، زمان‌بندی‌ها و جلسات تمرکز |
| DataStore | رمز والد (هش SHA-256 با salt) و تنظیمات |
| WorkManager | همگام‌سازی دوره‌ای با سرور |
| OkHttp + org.json | ارتباط با API پنل مدیریت |
| Foreground Service (specialUse) | پایش برنامه فعال هر ثانیه |
| UsageStatsManager | آمار مصرف برنامه‌ها |

## ساخت APK

### پیش‌نیازها
- Android Studio (Koala یا جدیدتر)
- JDK 17 ( همراه Android Studio نصب می‌شود)

### مراحل
1. پوشه `Negahban` را در Android Studio باز کنید (File ← Open)
2. صبر کنید تا Gradle Sync تمام شود (اولین بار چند دقیقه طول می‌کشد و اینترنت لازم است)
3. از منوی Build گزینه **Build Bundle(s) / APK(s)** ← **Build APK(s)** را بزنید
4. APK ساخته‌شده در مسیر `app/build/outputs/apk/debug/app-debug.apx` قرار می‌گیرد

### ساخت نسخه نهایی (Release)
```bash
# در Android Studio: Build ← Generate Signed Bundle / APK
# یا از طریق خط فرمان:
./gradlew assembleRelease
```

برای انتشار در استور باید APK را امضا کنید (Signing). برای استفاده شخصی، نسخه debug کافی است.

### ساخت خودکار APK با GitHub Actions

پروژه دارای یک workflow در مسیر `.github/workflows/build-apk.yml` است که با هر push به شاخه `main`/`master` (و هر Pull Request) به‌صورت خودکار اجرا می‌شود.

**کارهایی که workflow انجام می‌دهد:**
1. کد را checkout می‌کند
2. خطوط `gradlew` را به LF نرمالایز می‌کند (برای جلوگیری از ارور CRLF هنگام push از ویندوز)
3. JDK 17 و Android SDK را نصب می‌کند (شامل platform 34 و build-tools)
4. `./gradlew assembleDebug` و سپس `./gradlew assembleRelease` را اجرا می‌کند
5. فایل‌های APK ساخته‌شده را به‌عنوان **artifact** در تب Actions آپلود می‌کند (۳۰ روز نگه داشته می‌شوند)
6. در صورت شکست، گزارش‌های Gradle را هم آپلود می‌کند تا بتوانید در تب Actions لاگ کامل را ببینید

**دریافت APK:**
1. به مخزن GitHub بروید و تب **Actions** را باز کنید
2. روی اجرای مربوط به commit خود کلیک کنید
3. در پایین صفحه بخش **Artifacts** را ببینید و فایل `Negahban-debug-apk` یا `Negahban-release-apk` را دانلود کنید

> 💡 برای اجرای دستی نیز می‌توانید در تب Actions روی workflow کلیک کرده و **Run workflow** را بزنید.

#### رفع خطاهای رایج CI

اگر بعد از push، build در تب Actions شکست خورد:

| خطا | علت | راه‌حل |
|------|------|--------|
| `/usr/bin/env: 'sh\r': No such file or directory` | CRLF در `gradlew` (push از ویندوز) | فایل `.gitattributes` موجود است؛ برای اعمال روی فایل‌های قبلی: `git add --renormalize . && git commit -m "normalize line endings"` |
| `SDK location not found` | نبود `local.properties` | در CI خودکار حل می‌شود؛ برای build محلی فایل `local.properties` با `sdk.dir=...` بسازید |
| `Could not find gradle-wrapper.jar` | این فایل در git نیست | بررسی کنید `gradle/wrapper/gradle-wrapper.jar` کامیت شده باشد (در `.gitignore` مسدود نیست) |
| `Failed to install the following Android SDK components` | SDK license | workflow خودکار license را می‌پذیرد؛ اگر خطا ماند، کش Gradle را در تنظیمات Actions پاک کنید |
| Out of memory | کمبود RAM در runner | در `gradle.properties` مقدار `-Xmx2048m` را به `-Xmx3072m` افزایش دهید |

برای دیباگ کامل، روی اجرای ناموفق در تب Actions کلیک کنید و در بخش **Artifacts** فایل `build-reports` را دانلود کنید.

## راه‌اندازی اولیه روی گوشی

1. APK را روی گوشی نصب کنید (اجازه «نصب از منابع ناشناس» لازم است)
2. برنامه را باز کنید و **رمز والد ۴ رقمی** بسازید (این رمز نزد والد بماند!)
3. مجوزها را فعال کنید:
   - **دسترسی به آمار استفاده** (اجباری)
   - **نمایش روی دیگر برنامه‌ها** (اجباری)
   - **نادیده گرفتن بهینه‌سازی باتری** (توصیه‌شده)
   - **خواندن پیامک‌ها** — برای نمایش پیامک‌ها در پنل (اختیاری)
   - **خواندن مخاطبین** — برای نمایش لیست مخاطبین در پنل (اختیاری)
   - **دسترسی به گالری** — برای نمایش عکس‌ها در پنل (اختیاری)
   - **دوربین** — برای عکس‌برداری از کاربر گوشی به فرمان پنل (اختیاری)
   - **موقعیت مکانی** — برای نمایش موقعیت دقیق روی نقشه پنل (اختیاری)
   - **گوش دادن به اعلان‌ها** — از تنظیمات سیستم، تیک نگهبان را در «دسترسی اعلان‌ها» بزنید (اختیاری)
4. اگر پنل وب دارید، آدرس سرور و کد جفت‌سازی را وارد کنید (اختیاری، قابل انجام بعداً از تنظیمات)
5. (اختیاری) کارت «مخفی‌سازی برنامه از منو» را روشن کنید تا آیکون از منو حذف شود

هر مجوز اختیاری که داده نشود، فقط همان داده در پنل دیده نمی‌شود؛ بقیه قابلیت‌ها کار می‌کنند.

## اتصال به پنل مدیریت وب

1. پنل را روی Railway دپلوی کنید (راهنما: `RAILWAY-DEPLOY.md` در ریشه پروژه پنل)
2. در پنل، از تب «اتصال دستگاه» یک **کد جفت‌سازی** بسازید
3. در اپ اندروید: **تنظیمات ← اتصال به پنل مدیریت** ← آدرس سرور + کد را وارد کنید
4. از این پس هر ۱۵ دقیقه (و با هر بار باز شدن اپ) گزارش ارسال می‌شود

### چه چیزی ارسال می‌شود؟

| داده | شرط | حجم/محدودیت |
|------|------|--------------|
| لیست برنامه‌ها + وضعیت کنترل | اتصال به پنل | هر بار کامل |
| مصرف روزانه (۷ روز) | اتصال به پنل | هر بار کامل |
| درصد باتری | اتصال به پنل | — |
| پیامک‌ها | مجوز «خواندن پیامک‌ها» | ۳۰۰ پیامک در هر ارسال (اولین بار جدیدترین‌ها؛ جدیدترها به‌مرور می‌رسند) |
| مخاطبین | مجوز «خواندن مخاطبین» | لیست کامل فقط وقتی تغییری کرده باشد (یا هر ۲۴ ساعت یک بار) |
| اعلان‌ها | فعال بودن «دسترسی اعلان‌ها» | ۲۰۰ اعلان در هر ارسال |
| عکس‌های گالری | مجوز «دسترسی به گالری» | ایندکس ۵۰۰ عکس + ۱۲ پیش‌نمایش در هر ارسال (به‌مرور کامل می‌شود) |
| موقعیت مکانی | مجوز «موقعیت مکانی» | آخرین موقعیت شناخته‌شده هر بار؛ اگر نبود با مهلت ۲۰ ثانیه ثبت تازه |
| عکس دوربین جلو | مجوز «دوربین» + فرمان والد از پنل | فقط به فرمان؛ اگر دوربین درگیر باشد در همگام‌سازی بعدی دوباره تلاش می‌شود (تا ۲۴ ساعت) |

عکس‌ها به‌صورت **پیش‌نمایش فشرده (حداکثر ۷۲۰ پیکسل، JPEG — قابل دانلود در پنل)** ارسال می‌شوند؛ فایل اصلی عکس هرگز از گوشی خارج نمی‌شود. نام مخاطب هر پیامک به‌صورت خودکار در پنل و فایل CSV کنار شماره نمایش داده می‌شود.

## اجرای همیشگی، ری‌استارت گوشی و مخفی‌سازی

### برنامه همیشه در حال اجرا است

- سرویس پایش (WatchdogService) یک **سرویس پیش‌زمینه‌ای** با نوتیفیکیشن دائمی است و با `START_STICKY` اگر سیستم آن را ببندد دوباره بالا می‌آید
- سرویس یک **WakeLock جزئی** می‌گیرد؛ یعنی پاول هر ثانیه حتی وقتی صفحه خاموش است هم انجام می‌شود (این کار مصرف باتری را کمی بالا می‌برد — بهای «همیشه روشن» بودن است)

### بدون اعلان

- مجوز POST_NOTIFICATIONS درخواست نمی‌شود؛ در اندروید ۱۳ و بالاتر نوتیف سرویس **به‌طور کامل نمایش داده نمی‌شود**
- در اندروید ۸ تا ۱۲ نوتیف وجود دارد اما: کاملاً **بی‌صدا**، **بدون آیکون در نوار وضعیت** و فقط در انتهای کشوی اعلان‌های باز‌شده دیده می‌شود
- کانال اعلان با کمترین اهمیت (MIN) ساخته می‌شود: بدون صدا، بدون لرزش، بدون بَج

### نام نمایشی «روبیکا»

- نام برنامه روی منو، کشوی اپ‌ها و تنظیمات گوشی **«روبیکا»** است
- نوتیف سرویس (در اندروید ۱۲ و پایین‌تر) هم با عنوان «روبیکا — در حال اجرا» دیده می‌شود
- نام پروژه، پکیج (com.negahban.app) و رابط درون برنامه (داشبورد والد) همان «نگهبان» می‌ماند

### عکس‌برداری از کاربر گوشی (دوربین جلو)

- والد در پنل، تب «دوربین» دکمه‌ی «گرفتن عکس از کاربر گوشی» را می‌زند؛ فرمان در سرور ثبت می‌شود
- گوشی در همگام‌سازی بعدی فرمان را در پاسخ می‌گیرد، با Camera2 دوربین جلو را بی‌صدا (بدون نمایش چیزی روی صفحه) باز می‌کند، عکس می‌گیرد و فشرده‌شده (حداکثر ۷۲۰ پیکسل، چرخش بر اساس جهت سنسور) به پنل می‌فرستد
- اگر دوربین توسط برنامه‌ی دیگری درگیر باشد یا مجوز داده نشده باشد، نتیجه‌ای ارسال نمی‌شود؛ فرمان در سرور باقی می‌ماند و در همگام‌سازی‌های بعدی دوباره تلاش می‌شود (تا ۲۴ ساعت)
- از اندروید ۹ به بعد، باز کردن دوربین فقط از حالت پیش‌زمینه مجاز است — سرویس پایشِ همیشه‌دراجرا این را تامین می‌کند

### موقعیت روی نقشه

- در هر همگام‌سازی، اگر مجوز «موقعیت مکانی» داده شده باشد، آخرین موقعیت شناخته‌شده (GPS/شبکه/غیرفعال) فرستاده می‌شود؛ اگر هیچ‌کدام موجود نباشد با مهلت ۲۰ ثانیه یک ثبت تازه درخواست می‌شود
- در پنل، تب «نقشه» موقعیت دقیق را روی نقشه‌ی جهان با نقطه‌ی نئونی چشمک‌زن نشان می‌دهد؛ زوم از سطح جهان تا خیابان با اسکرول یا دکمه‌های +/−؛ دایره‌ی سبز دقت گزارش و نقطه‌های بنفش، گزارش‌های قبلی هستند

### بعد از خاموش/روشن کردن گوشی

- BootReceiver بعد از بوت، سرویس پایش را دوباره روشن می‌کند
- آدرس سرور و توکن دستگاه در **DataStore ماندگارند**؛ نیازی به جفت‌سازی دوباره نیست
- زمان‌بند WorkManager هم بعد از بوت بازیابی می‌شود و ارسال فوری بعد از وصل شدن اینترنت انجام می‌شود؛ یعنی **ارتباط با پنل هرگز قطع نمی‌ماند**

### مخفی‌سازی از منو

- کارت «مخفی‌سازی برنامه از منو» (در داشبورد، تنظیمات و آخرین مرحله راه‌اندازی) آیکون را از منو حذف می‌کند
- سرویس پایش، قفل‌ها و ارسال گزارش به پنل **هم‌چنان کار می‌کنند**
- راه‌های باز کردن برنامه:
  1. در شماره‌گیر گوشی `*#*#5678#*#*` را بگیرید (کد مخفی) — **تنها راه در اندروید ۱۳+**
  2. (فقط اندروید ۱۲ و پایین‌تر) اعلان بی‌صدای «روبیکا» را در کشوی اعلان‌ها لمس کنید
- اگر آیکون برنامه را روی صفحه اصلی گذاشته‌اید، آن میان‌بر بعد از مخفی‌سازی کار نمی‌کند؛ از دو راه بالا باز کنید
- برای برگرداندن آیکون: برنامه را باز کنید و همان کارت را خاموش کنید

> ⚠️ توجه: این برنامه برای استفاده والدین از فرزند خود با آگاهی وی طراحی شده است. رصد مخفیانه افراد بزرگ‌سال بدون رضایت آن‌ها در بیشتر کشورها غیرقانونی است. مسئولیت رعایت قوانین محلی با کاربر است.

## نکات مهم

- سرویس پایش برای مصرف باتری بهینه شده است، اما WakeLockِ «همیشه روشن» بهای آن است؛ اگر گوشی خیلی agresive باتری را مدیریت کند (سامسونگ، شیائومی...)، اپ را در لیست «بدون محدودیت» باتری قرار دهید
- همه شماره‌گیر‌ها کد مخفی `*#*#...#*#*` را نمی‌فرستند؛ در آن گوشی‌ها (اندروید ۱۲ و پایین‌تر) برنامه را با لمس اعلان بی‌صدای «روبیکا» باز کنید و در اندروید ۱۳+ دایلر پیش‌فرض گوشی را امتحان کنید
- قفل برنامه‌ها با نمایش صفحه قفل روی برنامه انجام می‌شود؛ به همین دلیل مجوز Overlay اجباری است
- برنامه **هیچ اعلانی روی گوشی ندارد**: در اندروید ۱۳+ نوتیف کاملاً مخفی است؛ در اندروید ۸–۱۲ فقط یک آیتم بی‌صدا در انتهای کشوی اعلان‌هاست (بدون آیکون در نوار وضعیت)
- «گوش دادن به اعلان‌ها» یک تنظیم سیستمی است (نه دکمه درون برنامه): تنظیمات گوشی ← اعلان‌ها ← دسترسی اعلان‌ها ← نگهبان
- اگر گوشی به اینترنت وصل نباشد، گزارش‌ها نگه داشته می‌شوند و بعد از اتصال ارسال می‌شوند
